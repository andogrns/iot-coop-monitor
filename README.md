# IoT Coop Monitor

ESP32-C3 poultry-coop air-quality early-warning prototype using an MQ-135 gas sensor, an AHT20/BMP280 module, an SSD1306 OLED, and MicroSD logging. The MQ-135 output is a relative gas response, not a calibrated ammonia concentration.

The current firmware, wiring, setup, calibration steps, CSV format, and offline checks are documented in [firmware/coop_monitor/README.md](firmware/coop_monitor/README.md).
